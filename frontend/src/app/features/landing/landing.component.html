Questions

Which channels can I connect?

App Store, Google Play, Zendesk, Trustpilot, a JMAP e-mail inbox and a Mastodon hashtag. Each connection can be paused without losing the comments already collected.

Can another company see my feedback?

No. Every record carries your company identifier and every query is filtered by it, so a request for a record that belongs to someone else is answered as if it did not exist.

Where are channel credentials kept?

Encrypted in the database. They are never written to a log or an error message.

What happens when the allowance runs out?

Collection continues and new comments are kept, waiting to be analysed. Nothing is deleted; once the plan is upgraded the waiting comments are analysed automatically.

Which languages are supported?

Comments are analysed in the language they were written in, detected automatically. The interface itself is available in Turkish and English.
